# Experiencia Patronal — LASERMAN (guion Suno)

## Qué hicimos
1. Guion original: voz masculina grave, hablada, con efectos entre corchetes.
2. Nueva estructura: golpes tardíos (el impacto cae después de la frase, con un respiro antes).
3. Estilo corto para el campo de estilo de Suno.

## Style (campo de estilo)
```
spoken word, deep male voice, fast, firm, no singing, no shouting, cinematic trailer, sub bass, reverse hits, delayed impacts, glitch, stutter, laser sweeps, dark epic electronic, spanish
```

- "que se quede como está" quedó fuera (parecía nota); agregarlo antes del HARD CUT si es letra.
- Si Suno lee los corchetes como letra, usar paréntesis o quitar efectos menores.
